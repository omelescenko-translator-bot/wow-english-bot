# 🚀 Пошаговая инструкция: Запуск бота и Mini App 24/7 на Render.com

Данное руководство позволит вам за **3–5 минут** развернуть приложение на **Render.com** (бесплатно, навсегда, с постоянным HTTPS-доменом).

---

## 📌 Шаг 1. Зайти на Render.com и создать Web Service

1. Перейдите на сайт [render.com](https://render.com/) и войдите в свой аккаунт (через GitHub / GitLab / Email).
2. В правом верхнем углу нажмите синюю кнопку **«+ New»** ➔ выберите **«Web Service»**.
3. Выберите ваш GitHub-репозиторий с проектом `English_Learning_Bot` (или подключите его через **«Connect a repository»**).

---

## 📌 Шаг 2. Настройки сервиса (Settings)

Заполните основные поля:

| Поле | Значение |
| :--- | :--- |
| **Name** | `wow-english-bot` *(или любое ваше название)* |
| **Region** | `Frankfurt (EU Central)` *(самый быстрый для Европы/СНГ)* |
| **Branch** | `main` *(или master)* |
| **Runtime** | `Python` |
| **Build Command** | `pip install -r requirements.txt` |
| **Start Command** | `python run.py` |
| **Instance Type** | **Free** ($0 / month) |

---

## 📌 Шаг 3. Добавить переменные окружения (Environment Variables)

Внизу страницы найдите раздел **«Environment Variables»** и нажмите **«Add Environment Variable»**:

1. **`BOT_TOKEN`**
   * **Значение:** `8979320080:AAGrNzTOizem6F0t26uli59t7AepTj5Zduo` *(токен вашего бота от @BotFather)*
2. **`GEMINI_API_KEY`**
   * **Значение:** ваш ключ Google Gemini API *(для мгновенного AI-перевода и умных категорий)*

---

## 📌 Шаг 4. Нажать кнопку «Deploy Web Service»

1. Нажмите внизу **«Deploy Web Service»**.
2. Render за 1-2 минуты установит зависимости и запустит бота:
   * В логах появится: `FastAPI сервер успешно запущен`, `Telegram бот @WOWEnglishAI_bot запускается мгновенно`.
3. Вверху страницы под названием сервиса появится ваш **постоянный HTTPS URL**, например:
   `https://wow-english-bot.onrender.com`
4. Бот **автоматически зарегистрирует этот адрес в Telegram**, и кнопка меню «Mini App» сразу станет активна для всех пользователей!

---

## ⏰ Шаг 5. Настройка вечного пинга 24/7 (чтобы бесплатный Render не засыпал)

> 💡 **Как работает бесплатный тариф Render:**
> Если к сервису нет обращений в течение 15 минут, он переходит в «спящий режим». Чтобы бот и WebApp отвечали мгновенно 24 часа в сутки 7 дней в неделю, достаточно настроить бесплатный автоматический пинг.

### Настройка на [cron-job.org](https://cron-job.org/) (занимает 1 минуту):
1. Зайдите на бесплатный сервис [cron-job.org](https://cron-job.org/) и зарегистрируйтесь.
2. Нажмите **«Create Cronjob»**.
3. **Title:** `Ping WOW English Bot`
4. **URL:** `https://ваш-проект.onrender.com/` *(вставьте URL вашего сервиса с Render)*
5. **Schedule (Расписание):** выберите **«Every 10 minutes»** (каждые 10 минут) или **«Every 5 minutes»**.
6. Нажмите **«Create»**.

🎉 **Готово!** Сервис `cron-job.org` будет каждые 5–10 минут отправлять фоновый запрос к вашему приложению, и Render **НИКОГДА не уснет** — бот и Mini App будут работать круглосуточно 24/7 без остановки и совершенно бесплатно!
